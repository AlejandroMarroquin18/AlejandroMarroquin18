# Alejandro Marroquín Almeida

## Sobre mí

Ingeniero de Sistemas con enfoque Full Stack y experiencia en Python, Django, FastAPI y React. He
desarrollado aplicaciones web, APIs y herramientas para automatización de procesos, trabajando con
PostgreSQL, Docker y servicios en la nube. Actualmente busco seguir desarrollándome profesionalmente en
proyectos de software donde pueda aportar mis conocimientos de backend y frontend.
